A chess engine in a few KB of Python: mailbox board, negamax alpha-beta search
with a transposition table, killer moves, null-move pruning, check extensions
and quiescence, packed through `makefun compress`. Built for make.fun's
"Build the strongest chess engine in 4 KB of Python" bounty. The search uses a
fixed node budget per move — no clock, no randomness.

## Run it

```sh
MAKEFUN_ENV_URL=<env url> python3 -P -s main.py
```
