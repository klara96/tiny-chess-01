A chess engine in 4 KB of Python (alpha-beta search with a fixed node budget, iterative deepening, transposition table, killer moves, quiescence search, PST evaluation). Deterministic: no wall clock, moves derive from the position, game history and trial seed.

## Run it

```sh
MAKEFUN_ENV_URL=<env url> python3 main.py
```
